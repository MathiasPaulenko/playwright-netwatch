# Security Policy

## Supported versions

Only the latest published release receives fixes.

## Reporting a vulnerability

netwatch observes network traffic in test environments — it holds no credentials and runs untrusted page traffic by design. If you still find a security issue (e.g., data exposure in reports, unsafe handling of request data):

- Prefer [GitHub private vulnerability reporting](https://github.com/MathiasPaulenko/playwright-netwatch/security/advisories/new).
- Otherwise open a regular issue without exploit details and ask for a private channel.

Expect a first response within a few days.
